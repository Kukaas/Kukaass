# Chester Luke A. Maligaso - Portfolio

A modern, responsive portfolio website built with Next.js 15, showcasing my skills, projects, and professional experience as a Full-stack Developer.

## 🌟 Features

- **Modern Design**: Clean, professional design with glass morphism effects
- **Responsive Layout**: Fully responsive across all devices
- **Dynamic Projects**: Admin panel to manage and showcase projects
- **SEO Optimized**: Built-in SEO with structured data and sitemap generation
- **Performance**: Optimized for speed with Next.js 15 features
- **Contact Integration**: Functional contact form with proper validation
- **Tech Stack Showcase**: Interactive display of technologies and skills
- **Image Carousel**: Dynamic project image galleries
- **Dark Theme**: Elegant dark theme with gradient backgrounds

## 🛠️ Tech Stack

### Frontend

- **Next.js 15** - React framework with App Router
- **React 19** - Latest React with concurrent features
- **TypeScript** - Type-safe development
- **Tailwind CSS 4** - Utility-first CSS framework
- **Framer Motion** - Smooth animations and transitions
- **Radix UI** - Accessible component primitives
- **Lucide React** - Beautiful icons

### Backend & Database

- **MongoDB** - NoSQL database with Mongoose ODM
- **Next.js API Routes** - Serverless API endpoints
- **Mongoose** - MongoDB object modeling

### Development Tools

- **ESLint** - Code linting
- **PostCSS** - CSS processing
- **Vercel Analytics** - Performance monitoring
- **Vercel Speed Insights** - Core Web Vitals tracking

## 📁 Project Structure

```
portfolio/
├── app/                    # Next.js App Router
│   ├── admin/             # Admin panel for project management
│   ├── api/               # API routes
│   ├── projects/          # Dynamic project pages
│   └── layout.tsx         # Root layout
├── components/            # React components
│   ├── ui/               # Reusable UI components
│   ├── Hero.tsx          # Hero section
│   ├── About.tsx         # About section
│   ├── Projects.tsx      # Projects showcase
│   ├── TechStack.tsx     # Skills and technologies
│   └── Contact.tsx       # Contact form
├── hooks/                # Custom React hooks
├── lib/                  # Utility functions and database
├── models/               # MongoDB models
├── public/               # Static assets
└── scripts/              # Database migration scripts
```

## 🎯 Key Components

### Main Sections

- **Hero**: Introduction and call-to-action
